Calculadora de data futura

Descubra uma data no futuro.

Como usar

Informe os valores solicitados e clique em calcular. O resultado aparece no navegador.

Verifique se o cálculo usa dias corridos ou úteis e se deve considerar feriados locais. O resultado pode mudar conforme o calendário adotado.

Como interpretar o resultado

O resultado depende dos valores inseridos e do método indicado nesta página. Confira as unidades, o período e as hipóteses antes de usar o número em uma decisão.

Sobre esta calculadora

Esta página mostra os dados informados, a fórmula ou método aplicável e uma interpretação simples do resultado.

Importante

Esta ferramenta é informativa. Em cálculos trabalhistas, fiscais, financeiros ou de saúde, confirme as regras aplicáveis.

Como interpretar o resultado

A ferramenta calculadora de data futura usa os dados informados para produzir uma estimativa. Confira o calendário, o período e a diferença entre dias corridos e úteis quando aplicável.

Confira a fórmula e o exemplo desta página e valide os dados de entrada antes de usar o resultado.
